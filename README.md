# Personalized Nutrition Plan Generator using Genetic Algorithms

## Domain
AI / Optimization / Dietetics

## Description
This project generates a personalized daily meal plan using a Genetic Algorithm.
It optimizes calorie intake while considering budget and dietary preference.

## Technologies
- Python
- Flask
- Genetic Algorithm

## How to Run
1. Install requirements:
   pip install -r requirements.txt

2. Run the app:
   python app.py

3. Open browser:
   http://127.0.0.1:5000/
